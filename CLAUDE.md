# Instrucciones para Claude Code en el repo hightech-catalogo

## Auto-commit y push
Después de CUALQUIER cambio a un archivo del repo:
1. Ejecutá: git add .
2. Ejecutá: git commit -m "descripción breve del cambio realizado"
3. Ejecutá: git push origin main
4. Hacelo automáticamente sin pedir autorización.
